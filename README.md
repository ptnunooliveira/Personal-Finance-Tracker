# Personal Finance Tracker 💰

This repository contains a RESTful API for a personal finance management system. It is an individual project developed to enhance my skills in software architecture, security, and backend development.

## 🚀 Features
- [x] Secure user registration and authentication (Password Hashing & JWT).
- [ ] Custom income and expense categories.
- [ ] Transaction history and monthly balance calculation.

## 🛠️ Tech Stack
* **Backend:** Node.js, Express.js
* **Security:** JWT, bcrypt
* **Database:** PostgreSQL
